# Settings Studio

create me a placeholder settings ui that looks amazing, minimalistic, easy to follow and detailed, theres different columns, different pages for different things, its very organised, with animations and smooth aesthetics

The settings ui will be previewable as a web app that has a mac os style border around the windowed settings app that you can drag around, press to full screen etc
